# Claude / Project Knowledge Adapter

Start with [`native-cli-mcp.md`](native-cli-mcp.md); this file adds Claude
Project Knowledge loading steps. CheckYourself is not Claude-specific.

## Path

1. Add this folder to project knowledge or the repo.
2. Point the file-aware tool at `CONTEXT.md` first; it is the canonical stage
   router.
3. Ask the assistant to read `AGENTS.md`, `rules.md`, and
   `PASTE_THIS_INTO_YOUR_AI.md`.
4. Run the diagnostic.
5. Approve fixes one at a time.
