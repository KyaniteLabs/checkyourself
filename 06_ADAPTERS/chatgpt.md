# ChatGPT Adapter

Start with [`native-cli-mcp.md`](native-cli-mcp.md) when a local shell or MCP
client is available. This file only covers ChatGPT's chat/file-sharing setup.

## Best path

1. Upload the project files you can share, or paste key files and app context.
2. Load the CheckYourself bootstrap (`PASTE_THIS_INTO_YOUR_AI.md`) as your operating instructions.
3. Ask for diagnostic mode first.
4. Use guided fix mode only after reviewing the report.

## Prompt

```text
Use the CheckYourself system. Start read-only. Diagnose first, then propose fixes for approval. After the diagnostic, generate my learning plan from the findings.
```
