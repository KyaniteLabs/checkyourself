Learning Priorities

Each item is tied to the v1.7.0 hardening pass and includes a source plus a relevant video.

1. A score is only as honest as it is hard to game

Absence of evidence is not proof of safety. A maturity score must treat missing or hand-waved coverage as Unknown, never as an automatic pass.

Next: When you add a scoring path, ask how someone would fake a perfect result, then close that path.

Success: Thin coverage scores low; only complete, evidenced coverage reaches 100/high.

Source: CheckYourself scoring methodWatch: evidence-based evaluation

2. Treat the input you scan as hostile

A tool that reads untrusted projects can be turned against its host: a symlinked file or an unconfined path becomes an exfiltration primitive.

Next: Never follow symlinks, confine every read and write to the target tree, and disclose anything you skip.

Success: An adversarial fixture cannot make the scanner read or report files outside the project.

Source: OWASP path traversalWatch: secret scanning
