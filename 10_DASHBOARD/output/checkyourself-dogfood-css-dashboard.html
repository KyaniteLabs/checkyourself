Learning plan snapshot

  • CI parity: Checks used to call a repo ready should be represented in CI or documented as manual gates.
  • Public launch proof: Local green status is not the same as GitHub Actions passing after push.
  • Agent eval fixtures: Prompt systems need small known-bad inputs to catch shallow diagnostic behavior.
