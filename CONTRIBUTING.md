# Contributing

CheckYourself welcomes contributions that make the diagnostic more useful, safer, clearer, or easier to use.

## Contribution principles

- Keep the beginner path simple.
- Do not add provider lock-in to the core workflow.
- Prefer evidence-based checks over vague advice.
- Do not weaken approval gates.
- Add examples when adding new concepts.
- Tie learning-plan improvements to real diagnostic findings.

## Good contribution types

- Better prompts.
- New adapter guides.
- Example reports for common stacks.
- Safer validation heuristics.
- More precise scoring guidance.
- Learning-plan mappings.
- Advanced capabilities.
