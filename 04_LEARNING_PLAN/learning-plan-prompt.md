# Learning Plan Prompt

```text
Create my CheckYourself learning plan.

Base it on the diagnostic findings, approved fixes, failed checks, unknowns, and score changes from this project.

Do not give me a generic full-stack curriculum.

For each learning topic, include:
- the finding that triggered it;
- the plain-English idea;
- the technical idea;
- one tiny exercise inside my app;
- one sign that I understand it;
- one trusted written source;
- one real relevant YouTube video from a trusted source when available;
- whether it is beginner, intermediate, or advanced;
- whether I need it now or later.

Also create:
- a 7-day plan for immediate progress;
- a 30-day plan for deeper skill;
- a glossary of terms used in the diagnostic;
- a “do not learn this yet” list to prevent overwhelm.

Language and accessibility:
- Detect my language and the dominant language of the project.
- If either is not English-only, make the plan bilingual and put the most useful language first.
- Write for ADHD, autism, and dyslexia: short paragraphs, concrete next actions, stable sections, and no dense textbook tone.
```
