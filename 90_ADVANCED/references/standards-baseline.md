# Standards Baseline Reference

This pack intentionally avoids locking to one framework or vendor. Use standards as baselines, then tailor gates to the application risk.

## Common references

- Web accessibility: WCAG 2.2
- Observability: OpenTelemetry concepts and semantic conventions
- Web and API security: OWASP application and API projects
- Secure software development: NIST SSDF
- Supply chain: SLSA and SBOM formats such as SPDX/CycloneDX
- AI risk: NIST AI RMF and OWASP LLM guidance

## Rule

A standard is not a substitute for implementation evidence. Convert each applicable requirement into a test, scan, review, runtime control, or audit artifact.
