# Learning Plan Stage Context

Use this stage to turn actual findings and remediations into a bespoke learning
plan.

## Inputs

| Input | Required? | Notes |
|---|---|---|
| Production Reality Report | Yes | Findings drive the curriculum. |
| Remediation history | Preferred | Improves level inference. |
| User goals or deadline | Optional | Adjust pacing, not the concepts. |

## Process

1. Read `04_LEARNING_PLAN/README.md`.
2. Use `learning-taxonomy.md` only to map findings to concepts.
3. Infer the user's level with confidence, and label uncertainty.
4. Build the plan from the actual findings, not a generic syllabus.
5. Include what to ignore for now.

## Outputs

| Output | Where |
|---|---|
| Bespoke Learning Plan | Chat by default, or `04_LEARNING_PLAN/output/bespoke-learning-plan.md` if file output is requested |
| Tiny project exercises | Included in the learning plan |

## Do Not

- Do not produce a generic course.
- Do not introduce advanced topics unless a finding makes them useful now.
