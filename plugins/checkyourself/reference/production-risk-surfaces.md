# Production Risk Surfaces

Use this list during diagnostics.

## User and data risks

- Authentication.
- Authorization.
- Session handling.
- Tenant/user data isolation.
- PII handling.
- Retention and deletion.
- Admin tools.

## Input and abuse risks

- Forms.
- Uploads.
- Webhooks.
- Public APIs.
- Search.
- Rate limits.
- Payment flows.

## Operational risks

- Secrets.
- Environment config.
- Deployment.
- Rollback.
- Migrations.
- Logs.
- Metrics.
- Errors.
- Alerts.
- Backups.
- Recovery.

## AI-specific risks

- Unsupported claims.
- Missing citations.
- Prompt injection.
- Unsafe tools.
- Cross-user memory/context leakage.
- Retrieval quality.
- Model/provider failure.
- Evaluation gaps.
