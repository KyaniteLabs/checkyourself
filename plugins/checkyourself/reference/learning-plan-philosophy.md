# Learning Plan Philosophy

The best learning plan is not a generic syllabus.

It is a map from the user's own mistakes, gaps, and fixes to the concepts they need next.

## Good learning item

- Triggered by a finding.
- Explains why it matters in the app.
- Gives one small exercise in the app.
- Defines terms.
- Has a success signal.

## Bad learning item

- Generic.
- Too broad.
- Not tied to the diagnostic.
- Too advanced for the immediate problem.
- Does not include practice.
