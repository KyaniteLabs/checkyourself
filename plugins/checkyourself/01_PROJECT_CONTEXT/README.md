# 01 — Project Context

Use this folder to give CheckYourself enough context to diagnose your app.

You do not need to know every answer. Unknowns are allowed. The diagnostic should label uncertainty instead of pretending.

## Best inputs

Add or describe:

- what the app does;
- who uses it;
- what users can create, see, edit, delete, or pay for;
- the stack, if you know it;
- where auth happens;
- where data lives;
- how it is deployed;
- what tests exist;
- what would be bad if it broke.

Use [`app-profile-template.md`](app-profile-template.md) if you want a guided form.

Use [`unknowns-and-assumptions.md`](unknowns-and-assumptions.md) to track missing context.
